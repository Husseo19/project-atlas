# ADR-0002: Focus on Microsoft Certifications First

**Date**: 2026-07-24
**Status**: Accepted

## Context
We need to select a starting point for our certification content generation and platform validation.

## Decision
We will focus exclusively on Microsoft certifications (e.g., AZ-900, AZ-104, AZ-305, SC-900) for the initial launch.

## Reasons
1. **Large Market**: High demand from both individuals and enterprises.
2. **Clear Blueprints**: Microsoft provides exceptionally clear and structured exam objectives, which aligns perfectly with our deterministic Learning Engine and Question Factory.
3. **Focused GTM**: Easier to market a specialized tool than a generic one.

## Consequences
- We will tailor our initial domain models slightly toward the Microsoft ecosystem (though keeping them abstract enough for future expansion).
- AWS, GCP, and CompTIA support is deferred to later roadmap phases.
